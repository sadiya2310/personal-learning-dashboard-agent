# How to install the Personal Learning Dashboard Agent

This skill builds you a private personal learning dashboard, in your
own field, starting empty with your own settings. Nothing is shared
with the person who sent it to you.

## What you need

- The skill file: `personal-learning-dashboard-agent-skill.md`
- Muse (the app or website where you chat with Muse)

There is no one-tap "install agent" button. You install it by giving
the file to your Muse in chat and asking Muse to save and use it.

## Steps

1. **Get the skill file**
   Save the file sent to you: `personal-learning-dashboard-agent-skill.md`.

2. **Open a new chat with Muse**
   Start a fresh chat, so the dashboard is built for you only.

3. **Attach the skill file and send this message**

   Attach `personal-learning-dashboard-agent-skill.md` to your message,
   then send:

   > Install this as a custom skill called
   > personal-learning-dashboard-agent, and use it to build me my
   > personal learning dashboard.

4. **Answer Muse's setup questions**
   Muse will ask you for:
   - Your field (for example: law, medicine, engineering, design)
   - The topics you want to learn
   - How long you want each session to be (15 to 90 minutes,
     default 30)

   Example answer for a lawyer:
   > I'm a lawyer. Topics: contract law, case analysis, and legal
   > writing. 30 minutes.

   Muse will then build your dashboard with exactly those topics.
   It starts empty — no lessons, notes, or settings from anyone else.

5. **Use your dashboard**
   - Read one real, verified article at a time, inside the dashboard.
   - Take notes: notes are filed by topic, and each saved note is
     automatically tagged with its article link as Proof.
   - Edit or Delete any note. The button to save a note is
     **Save note**.
   - Select text in an article to Ask AI in Explain This, or to add
     it as a note.
   - If you start a note and leave without saving — even if you
     switch to Explain This — your draft is saved and restored
     when you come back. It clears only when you save the note
     or discard the draft.

6. **Add or change topics later**
   - In the dashboard, go to Settings → What you're learning →
     **+ Add a new topic**, or
   - Just tell Muse in chat, for example:
     > Add employment law to my topics.

## Troubleshooting

- **Muse asks what the file is:** tell it, "It is a skill. Save it
  as personal-learning-dashboard-agent and follow it to build my
  dashboard."
- **Topics from someone else appear:** they should not. Start a
  fresh chat, install the skill again, and give Muse only your own
  field and topics.
- **You cannot find the skill file:** ask the person who sent it to
  resend `personal-learning-dashboard-agent-skill.md`.

## What is not shared

Your dashboard, lessons, notes, topics, and settings are private
to you. Sending or installing this skill does not give anyone
access to your Muse account, and it does not share your learning
with the person who sent you the skill.
